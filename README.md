# Ứng dụng Chat Nhóm Ẩn Danh

## Hướng dẫn cài đặt và chạy:

1. Yêu cầu máy tính đã cài đặt **Node.js**.
2. Giải nén thư mục này.
3. Mở Terminal / CMD tại thư mục dự án và chạy lệnh cài đặt thư viện:
   ```bash
   npm install
   ```
4. Khởi động server:
   ```bash
   npm start
   ```
5. Mở trình duyệt và truy cập: `http://localhost:3000` (Giao diện sẽ tự động chuyển hướng sang trang đăng nhập `login.html`).
